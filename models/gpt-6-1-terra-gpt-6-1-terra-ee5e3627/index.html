GPT-6.1 Terra · gpt-6.1-terra

OpenAI released GPT-6.1 Terra for visual reasoning, computer use and writing. It accepts text and image input and produces text output, with a documented 1,050,000-token context window. Standard API prices start at $1 per million input tokens and $5 per million output tokens; long-context and processing conditions apply.
