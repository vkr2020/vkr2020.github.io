Alibaba releases Qwen3.8-27B as an Apache 2.0 open-weight multimodal model for local coding and reasoning

First source report 18 Aug 2026Latest development 18 Aug 20261 source link

Alibaba has released Qwen3.8-27B on Hugging Face under an Apache 2.0 license, making the 27-billion-parameter multimodal model available as downloadable weights rather than only through a cloud API. VentureBeat reports the model supports image and video understanding, a 262,144-token context window, configurable reasoning, and coding and agentic workflows, with quantized versions small enough to run on high-end local hardware.
