Cursor launches Origin code hosting platform for paid users

First source report 17 Aug 2026Latest development 17 Aug 20262 source links

Cursor has begun rolling out Origin, its own code hosting platform, to paid users. VentureBeat framed the launch against a same-day GitHub outage that affected core developer services including pull requests, API access, enterprise single sign-on, and Copilot, but the discrete news is Cursor's product release.
