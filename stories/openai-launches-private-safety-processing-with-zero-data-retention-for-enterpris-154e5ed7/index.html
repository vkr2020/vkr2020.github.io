OpenAI launches Private Safety Processing with zero data retention for enterprise customers

First source report 19 Aug 2026Latest development 20 Aug 20262 source links

OpenAI introduced Private Safety Processing, a privacy-focused enterprise feature that it says enables automated safety monitoring without retaining customer prompts or responses. The move is aimed at businesses handling sensitive data and positions OpenAI more directly against Anthropic on trust, compliance, and enterprise data-governance assurances.
