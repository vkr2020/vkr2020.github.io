Google launches Gemini 3.7 Flash with coding and agent upgrades plus temporary lower API pricing

First source report 13 Aug 2026Latest development 13 Aug 20262 source links

Google has launched Gemini 3.7 Flash, a new version of its fast Gemini model line focused on coding, agentic workflows, and knowledge-work tasks. The company says the release follows Gemini 3.6 Flash by about three weeks and pairs model improvements with introductory API pricing of $0.75 per million input tokens and $3.75 per million output tokens through the end of 2026, after which prices are set to rise.
