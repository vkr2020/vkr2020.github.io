Snowflake adds dynamic model routing to Cortex AI Gateway

First source report 18 Aug 2026Latest development 18 Aug 20261 source link

Snowflake has added dynamic model routing to Cortex AI Gateway, letting enterprise users choose an automatic mode that selects a model for each request based on a quality-cost tradeoff instead of pinning workloads to a single model. The company says the feature can reduce token costs by up to 3x on some workloads, based on internal testing, and positions it as part of a broader push to make enterprise AI agents cheaper and better governed.
