OpenAI adds Computer History to the ChatGPT macOS app

First source report 16 Aug 2026Latest development 16 Aug 20262 source links

OpenAI has added a new Computer History feature to the ChatGPT desktop app for macOS, according to The Verge. The feature records user activity such as clicks and keystrokes to build a timeline that ChatGPT and Codex can reference for assistance, automation suggestions, and resuming unfinished tasks.
