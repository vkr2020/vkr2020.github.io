TrueFoundry open-sources TrueForge agent harness and touts lower task-completion costs

First source report 19 Aug 2026Latest development 19 Aug 20261 source link

TrueFoundry has released TrueForge, an open-source AI agent harness under the MIT License, aimed at giving developers and enterprises more control over agent behavior, tooling, and hosting. The company says benchmark tests on DevRev's Enterprise-Bench showed lower task-completion costs than Anthropic's Claude Managed Agents, including reported savings when using both GLM-5.2 and Claude Opus 4.8. The article centers on a discrete product release and performance claim from TrueFoundry.
