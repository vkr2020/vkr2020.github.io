OpenAI launches Decisions API for classification and routing, with up to 400 questions per request

Source dated 22 Oct 2026Latest development 22 Oct 20261 source link

OpenAI made its Decisions API generally available for bounded decisions such as classifying inputs and choosing a workflow’s next action. Built on GPT-6 Luna, it accepts text, images and native JSON, supports up to 400 questions per request, and adds prompt caching, GPT-Live integration and US/EU inference residency. Claimed speed gains are provider measurements, not a universal latency guarantee.
