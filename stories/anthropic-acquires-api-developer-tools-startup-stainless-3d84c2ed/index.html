Anthropic acquires API developer-tools startup Stainless

First source report 18 May 2026Latest development 18 May 20261 source link

Anthropic has acquired Stainless, a New York-based startup that automates the creation and maintenance of software development kits for APIs, according to TechCrunch. Stainless had built tooling used by companies including OpenAI, Google, and Cloudflare. The deal points to Anthropic expanding its control over developer tooling around API-based software adoption.
