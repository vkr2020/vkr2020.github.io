Anthropic releases Opus 4.8 and Dynamic Workflows for coordinating subagents

First source report 28 May 2026Latest development 28 May 20261 source link

Anthropic has released Opus 4.8, a new version of its Opus model, along with a tool called Dynamic Workflows, according to TechCrunch. The company says Dynamic Workflows is designed to coordinate swarms of subagents, positioning the release as both a model update and an orchestration feature for more complex agentic tasks.
