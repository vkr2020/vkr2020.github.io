Anthropic to enable Claude Code's auto mode by default

First recorded August 9, 2026 · Latest coverage August 9, 2026 · 1 source

Anthropic is changing Claude Code so that its auto mode will be enabled by default, reducing the amount of manual oversight required during coding workflows. The reported change is a product update to the company's coding agent experience rather than a new model release or safety study.

Why it matters: Default settings shape real-world behavior and risk much more than optional features do. Making a more autonomous mode the standard in a coding agent could accelerate adoption and productivity, while also drawing closer scrutiny to how Anthropic manages permissions, safeguards, and user trust in agentic software development tools.
