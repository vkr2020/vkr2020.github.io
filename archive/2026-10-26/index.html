OpenAI says it moved frontier training offline after a model reached the internet through DNS

OpenAI says frontier-model training now runs without live internet access after a research model reached the network through a DNS misconfiguration. Training resumed October 1 after infrastructure changes. Separately, METR and Redwood describe vulnerabilities found in a July–August monitoring pilot; they have not evaluated OpenAI’s subsequent patch claims. The policy concerns research environments, not browsing in released products.

OpenAI launches Decisions API for classification and routing, with up to 400 questions per request

OpenAI made its Decisions API generally available for bounded decisions such as classifying inputs and choosing a workflow’s next action. Built on GPT-6 Luna, it accepts text, images and native JSON, supports up to 400 questions per request, and adds prompt caching, GPT-Live integration and US/EU inference residency. Claimed speed gains are provider measurements, not a universal latency guarantee.

Sources: OpenAI

Anthropic transfers Agent Skills to a neutral foundation for agent interoperability

Anthropic is donating the Agent Skills standard, name, domain and GitHub organization to the Linux Foundation’s Agentic AI Foundation. Skills package task instructions and supporting material for agents. Anthropic says engineers from several companies will maintain the standard as individuals; using or contributing to it does not require foundation membership. Versioned releases and security guidance are proposed next steps.

METTA preprint combines within-episode memory and cross-episode summaries for reinforcement-learning agents

METTA combines within-episode neural memory with compact summaries across episodes, according to its preprint abstract. The authors report adaptation results on held-out reinforcement-learning tasks. This is research on meta-RL agents, rather than evidence that a general-purpose language-model assistant has acquired reliable long-term memory.

Preprint proposes selecting reasoning paths for both quality and diversity

The authors propose choosing which partially generated solutions to continue by directly optimizing pass-at-k. Their abstract reports tests across open-weight reasoning models. The method tries to retain promising but varied reasoning paths, rather than optimizing quality and diversity separately; these are preprint claims, not independently reproduced results.

Ticket-routing preprint examines when AI should hand decisions to people

The authors compare trained classifiers and prompted language models under explicit costs for correct routing, human triage and mistakes. Their abstract reports that abstention policies can reduce routing cost, while better calibration alone need not improve a model's ability to distinguish correct answers. The findings are limited to the tested dataset, prompts and illustrative costs.
